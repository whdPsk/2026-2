# 오프라인 저장과 모바일 화면

게시된 사이트 우측 하단 **오프라인 저장 → 전체 자료 저장**을 누르고 완료 표시를 확인한다. 같은 기기·브라우저에서 네 과목과 기말 공부계획을 인터넷 없이 다시 열 수 있다. 약 29 MB이며 실제 크기는 저장 대화상자에서 확인한다. 원본 eTL/Drive PDF·외부 영상은 포함하지 않는다.

수식 표시용 MathJax와 지연 로딩 구성요소도 같은 사이트에 배포해 함께 저장한다. 모든 과목 데이터와 출처 팝업 데이터가 포함되므로 미리 각 단원을 방문할 필요가 없다. 완료 기록·메모의 기존 저장 키는 유지한다. 다른 기기에는 자동 동기화되지 않으며 브라우저 데이터를 지우면 저장 자료·기록이 사라질 수 있다.

저장본의 빌드 시각은 KST로 표시한다. 온라인 재방문 시 새 버전을 확인하고 별도 캐시에 저장한다. 전체 파일의 SHA-256이 일치해야 완료 처리하며, 실패하면 기존 저장본을 유지한다. 새 자료가 준비되면 **새 자료 적용·새로고침**으로 전환한다. 브라우저가 저장 자료를 제거한 경우 **전체 자료 저장**으로 복구할 수 있다.

모바일에서는 단원 목록·검색을 접고 펼치며, 긴 수식과 표는 가로 스크롤한다. 공부계획을 시험 요약보다 먼저 표시하고 주간 화면은 날짜별 세로 목록으로 표시한다.

개발 서버는 오프라인 저장을 등록하지 않는다. `npm run build`로 생성된 `dist/`를 HTTPS 또는 localhost로 제공해 확인한다. `npm run check:offline`은 생성된 서비스 워커를 네트워크 차단 환경의 테스트 하네스에서 실행해 모든 저장 파일, 주소 별칭, 실패한 갱신, 캐시 격리·복구를 검증한다. 실제 모바일의 화면 배치·브라우저 설치 과정 검증을 대체하지는 않는다.

빌드 시 `scripts/offline-build.mjs`가 MathJax 파일과 라이선스, 파일별 해시, 서비스 워커, 저장본 정보를 생성한다. `dist/` 생성물은 커밋하지 않는다. 캐시 범위는 배포 하위 경로에 한정되며 이전 버전 하나를 남겨 이미 열린 탭의 파일 요청을 처리한다. 구현은 [서비스 워커 수명주기](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)를 따른다.
