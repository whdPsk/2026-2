# 강의 콘솔 자동 업데이트 운영 지침

대상: 이 저장소의 GitHub Pages 사이트. 실제 게시 원본은 루트 `content/`, `site/`, `scripts/`이다. `lecture-console/`은 참고용 별도 구현이다. 과목과 출처 정보는 `lecture-console/docs/registry.json`을 참고한다.

이 절차는 사용자가 이 대화에서 "강의 콘솔 업데이트해줘"라고 지시할 때만 실행한다. 예약·주기 실행은 설정하지 않는다. 현재 사이트의 전체 템플릿·디자인·탐색 구조를 유지하고, 새 자료의 내용 반영에 필요한 부분만 수정한다.

## 1. 자료 발견과 누락 방지

1. 첫 실행에서는 학기 시작 이후의 eTL 과제·공지·모듈, Drive 과목 폴더와 하위 폴더, 다글로 녹음·저장된 YouTube 영상을 전수 목록화한다. 이후 실행은 마지막 **성공한** 점검 시각보다 앞에서 시작하는 겹침 구간을 다시 조회하고, 정기적으로 학기 전체 목록과 대조한다. 임의의 최근 7일 제한만으로 완료를 판단하지 않는다.
2. 자료마다 출처의 고유 ID, 수정 시각, 과목, 제목, 강의 날짜, 유형, 처리 상태를 기록한다. 제목이 같아도 ID가 다르면 별개로 보고, ID가 같아도 수정 시각이 바뀌면 재검토한다. 같은 강의의 PPT·속기·다글로·과제·공지는 각각 별개 자료로 기록한다.
3. 각 자료를 작은 단위로 대조한다. PPT는 슬라이드와 불릿·문항, 녹음·속기는 시간 구간과 질문·답, 과제는 문항과 마감일, 공지는 개별 변경 사항을 확인한다. 단위마다 `반영`, `중복 근거 연결`, `내용 없음`, `확인 필요` 중 하나의 사유와 사이트 반영 위치를 남긴다. 단순히 제목이 장부에 있거나 장부의 기존 항목 인용률이 100%라는 이유만으로 무누락을 선언하지 않는다.
4. eTL·Drive·다글로 중 하나라도 접속이 실패하면 그 출처를 `미확인`으로 표시한다. 해당 과목의 전수 확인이 끝난 것으로 보고하지 않는다. 다른 확인 가능한 자료는 처리할 수 있으나 누락 검사 결과에는 미확인 범위를 명시한다.

## 2. 다글로 강의 노트

새 녹음본과 다글로에 저장된 YouTube 영상 각각에서 스크립트와 `템플릿 요약 → 학습 → 강의 노트` 결과 유무를 확인한다. 결과가 없으면 템플릿을 실행하고 완료된 결과를 다시 확인한다. 진행 중·실패 상태는 완료로 기록하지 않으며, 이미 생성된 결과는 중복 실행하지 않는다.

강의 노트 요약은 빠진 주제와 시간대를 찾는 보조 자료다. 사이트 내용은 반드시 원본 스크립트·PPT·속기와 대조한다. 다글로 요약에서 새로 등장한 공식, 수치, 시험 예상 문구는 원본에서 확인되지 않으면 사실로 옮기지 않는다. STT가 불확실한 물리 용어는 `확인 필요`로 남긴다.

## 3. 교재와 공개 범위

천체물리학개론1은 필요할 때 컴퓨터 제어로 알라딘 PC 뷰어의 구본철·김웅태 『천체물리학』 관련 절을 참고한다. 절·쪽수·예제 번호를 메모하고 강의 자료와 대조한다. 교재 본문이나 페이지 이미지를 사이트에 옮기지 않고 설명을 직접 쓴다. 뷰어에 접근할 수 없으면 교재 확인을 `미확인`으로 표시한다.

과제 풀이와 사이트 원본 파일은 마감 전에도 공개한다. `hw.json`의 `due`는 마감일 표시에만 사용한다. eTL·Drive·사용자 기존 파일은 읽기만 한다. 다글로에는 요청된 강의 노트 템플릿 결과만 생성한다.

## 4. 게시 검증

과목별로 자료 목록 수, 원자 단위 장부 수, 실제 본문 반영 수, 보류 수를 대조한다. 새 자료가 있는데 장부가 없거나, 확인하지 않은 시간 구간·슬라이드·문항이 있으면 `완료`로 기록하지 않는다. `npm run build`, `npm run lint:tex`, `npm run check`를 통과시키고 변경 내역을 살핀 뒤 커밋·푸시한다. GitHub Actions와 공개 페이지에서 배포 성공을 확인한 후에만 성공 상태를 기록한다. 실패한 실행은 다음 실행에서 다시 검사한다.

## 5. 로컬 저장 공간

GitHub 저장소를 편집 가능한 원본, GitHub Pages를 열람용 사이트로 사용한다. 원본 녹음·강의 PDF·전자책 파일은 사이트 빌드에 필요하지 않으면 새로 내려받아 저장하지 않는다. 일시적으로 받은 파일, `node_modules/`, `dist/`, 새 임시 체크아웃은 사용 후 정리한다. 기존 사용자 폴더나 전자책 뷰어의 데이터를 자동 삭제하지 않는다. 기존 로컬 저장소 제거는 원격 저장소와 Pages에 필요한 내용이 모두 있고 다시 내려받아 빌드할 수 있음을 확인한 뒤 별도로 진행한다.

## 보고

과목별 새 자료와 강의 날짜, 다글로 강의 노트 생성 여부, 장부 커버리지, 새 강조점·예제·과제 마감일, 미확인 자료와 이유, 배포 결과를 짧게 보고한다. 모든 출처가 정상 확인되고 신규·수정 자료가 없을 때만 `변경 없음`으로 판단한다.
