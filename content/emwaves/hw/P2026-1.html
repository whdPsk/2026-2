풀이·검산 경로

실제로 토의한 모든 사람과 실제 사용 도구명·버전·입력한 모든 질문을 두 파일에 동일하게 적는다. 사용하지 않았을 때만 “토의한 사람 없음”, “AI 도구 사용하지 않음”이라고 쓴다. 이 사이트의 도움을 사용했다면 실제 사용 내역도 정확히 포함한다. PDF에는 전 문항 답·그림·오차 분석, .py에는 전체 계산과 결과 출력을 넣는다.

NumPy·Matplotlib만 사용하고 SciPy를 사용하지 않는다. python abc.py로 실행되게 하며 노트북·특정 IDE 의존성을 없앤다. 코드 교환 금지와 하루 10% 지각 감점은 원문 기준이다.
