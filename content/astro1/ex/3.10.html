PPT Review Q① · 9/15 수업 문제
For the EM waves with \(E_x'=\epsilon_0\cos\beta\cos(kz-\omega t)\), \(E_y'=\epsilon_0\sin\beta\sin(kz-\omega t)\), discuss how the polarization of the waves changes as \(|\beta|\le\pi/2\) varies.
(번역) 위 전자기파에서 β가 \(|\beta|\le\pi/2\) 범위에서 변할 때 편광이 어떻게 달라지는지 논하라. [[L05.s3a]]
풀이타원 방정식 → 특수각 → 회전 방향
  1. z = 0에서 \(E_x'=\varepsilon_0\cos\beta\cos\omega t\), \(E_y'=-\varepsilon_0\sin\beta\sin\omega t\) (cos 우함수, sin 기함수). [[F11.08]]
  2. \((E_x'/\varepsilon_0\cos\beta)^2+(E_y'/\varepsilon_0\sin\beta)^2=1\) → 반축 \(\varepsilon_0|\cos\beta|\), \(\varepsilon_0|\sin\beta|\)인 타원. [[F11.09, S0915.03]]
  3. β = 0 → x′ 선편광, β = ±π/2 → y′ 선편광, β = ±π/4 → 원편광, 나머지 → 타원. [[F11.11, F12.06, F12.07]]
  4. β > 0: t = 0에 x′축 끝 → t 증가 시 \(E_y'\) 음수 쪽으로 → 시계 방향(빛을 마주 볼 때). 엄지를 관측자 쪽(+z)으로 두면 왼손 → LCP. β < 0 → 반시계 → RCP. [[F11.10, F12.10, S0915.03]]
  5. Stokes로 검산(χ = 0): \(I=\varepsilon_0^2,\ Q=\varepsilon_0^2\cos2\beta,\ U=0,\ V=-\varepsilon_0^2\sin2\beta\). β = 30° → (1, 0.5, 0, −0.866): V < 0 = LCP ✓ (python 수치 적분으로 회전 방향과 부호 확인).
결과

|β| 0 → 45° → 90°: 선(x′) → 납작한 타원 → 원 → 타원 → 선(y′). 부호: β > 0 = 시계 = LCP(V < 0), β < 0 = 반시계 = RCP(V > 0). |β|는 ellipticity, 부호는 손잡이.

함정fixed time(공간 나선)과 fixed space(z = 0, 시간 회전)의 회전 sense가 반대로 보인다 — 손잡이는 fixed space 기준. 교수님 "Left-handed, Right-handed 구별할 수 있어야." [[F12.09, S0915.03]]
+α β = 60°이면 장축:단축 비와 손잡이는?
스스로 채점:
Answer

cos60°:sin60° = 1:1.73 → 장축이 y′ 쪽(|sinβ| > |cosβ|). β > 0 → 시계 → LCP. V = −sin120° = −0.866ε₀².

+α β = −45°, χ = 0의 Stokes 벡터는?
스스로 채점:
Answer

(I, Q, U, V) = ε₀²(1, 0, 0, +1) — 순수 RCP.
