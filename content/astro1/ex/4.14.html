9/17 수업 문제(보기 1–4, 다수결)
중심별이 UV 복사를 사방으로 방출하고, 주변 대기에 자유전자가 많이 분포한다. 관측자가 별 근처의 전자에 의해 산란되어 오는 빛을 볼 때 편광 벡터(전기장 방향)는 어떻게 되는가? [[S0917.25, L06.s9]]
풀이입사 편광을 두 성분으로
  1. 별→전자 방향으로 진행하는 무편광 빛을 (가) 시선 방향(스크린 안팎) 진동, (나) 하늘 평면 안에서 진행 방향에 수직인 진동으로 나눈다. [[S0917.25]]
  2. (가)는 전자를 시선 방향으로 흔든다 → 관측자 방향이 쌍극자 축(Θ=0) → \(\sin^2\Theta=0\), 관측되지 않음. [[S0917.26]]
  3. (나)는 전자를 시선에 수직으로 흔든다 → 관측자에게 최대로 도달. 편광 벡터 = 별–전자 선에 수직. [[S0917.26]]
  4. 위·아래·45° 어느 위치든 같은 논리 → 별 둘레 동심원(접선) 패턴. 이런 패턴을 보면 "산란광"임을 안다. [[S0917.26]]
결과

편광 벡터는 각 위치에서 반지름(별 방향)에 수직 = 접선 방향, 전체로 동심원 패턴. 별과 같은 하늘 평면에 있는 전자(산란각 90°)에서 100% 편광. 수업 다수결은 1번 3명 — 보기 그림은 녹음에서 확인 불가.

흔한 오답"편광 벡터가 별을 향해 방사상" — 이는 \(\mathbf E\)가 진행 방향(별→전자)과 나란하다는 뜻이라 횡파 조건에 어긋난다. 산란 빛의 \(\mathbf E\)는 입사 진행 방향과도, 산란 진행 방향과도 수직. [[S0917.26]]
+α 같은 별을 거의 정면(입사 방향, θ≈0)에서 보는 산란광은 편광되는가?
스스로 채점:
Answer

θ=0이면 두 성분이 같아 Π = 0 — 무편광(예: 별 바로 뒤의 전자가 정방향으로 산란).

+α 중심 광원이 원반 모양으로 늘어나 있으면(점광원이 아님) 동심원 패턴의 편광도는 어떻게 되는가?
스스로 채점:
Answer

산란점에 여러 방향에서 빛이 들어와 각 성분이 부분적으로 상쇄 → 편광도 감소(패턴 방향은 대체로 유지).
