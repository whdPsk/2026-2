◈ 먼저 예측하기. 막대 양 끝에 추를 단 아령을, 막대가 회전축과 비스듬한 각 \(\alpha\)를 이루도록 축에 붙여 돌린다. 각속도 \(\boldsymbol\omega\)는 축 방향이다. 각운동량 \(\vb L=\sum m\,\vb r\times\vb v\)는 어느 방향일까 — 축 방향? 막대에 수직? 그리고 \(\vb L\)이 방향을 계속 바꾼다면 축을 붙잡은 베어링은 무엇을 해 줘야 할까?

11.4 강체의 각운동량 angular momentum

유도 1\(L_i=\sum_jI_{ij}\omega_j\) (필수)
  1. 기준점 \(O\)는 (a) 물체의 한 점이 고정되어 있으면 그 점, (b) 아니면 CM. 그러면 \(\vb p_\alpha=m_\alpha\boldsymbol\omega\times\vb r_\alpha\).
  2. \[ \vb L=\sum_\alpha m_\alpha\,\vb r_\alpha\times(\boldsymbol\omega\times\vb r_\alpha)=\sum_\alpha m_\alpha\left[r_\alpha^2\boldsymbol\omega-\vb r_\alpha(\vb r_\alpha\cdot\boldsymbol\omega)\right] \] (BAC−CAB).
  3. \(i\) 성분: \(L_i=\sum_\alpha m_\alpha\left[\omega_ir_\alpha^2-x_{\alpha,i}\sum_jx_{\alpha,j}\omega_j\right]=\sum_j\omega_j\sum_\alpha m_\alpha\left(\delta_{ij}r_\alpha^2-x_{\alpha,i}x_{\alpha,j}\right)\).
  4. 괄호 합이 \(I_{ij}\)이므로 \[ \boxed{\ L_i=\sum_jI_{ij}\omega_j\quad\Longleftrightarrow\quad\vb L=\I\cdot\boldsymbol\omega\ } \]
  5. 결정적 결과: 비대각 성분이 있으면 \(\boldsymbol\omega=(\omega,0,0)\)이어도 \(\vb L=(I_{11},I_{21},I_{31})\omega\) — \(\vb L\)과 \(\boldsymbol\omega\)는 일반적으로 평행하지 않다.
  6. \(\sum_i\omega_iL_i=\sum_{ij}I_{ij}\omega_i\omega_j=2T_{\rm rot}\) → \(T_{\rm rot}=\tfrac12\boldsymbol\omega\cdot\vb L\). (텐서·벡터 → 벡터, 텐서·벡터·벡터 → 스칼라.)
유도 2비스듬한 아령 — Example 11.10 (그림 11-4, 11-11)
  1. 가벼운 막대 양끝 \(m_1,m_2\), 원점(축 위의 막대 중점)에서 거리 \(b\). 물체계: \(x_3\)을 막대 방향, \(x_2\)는 막대와 \(\boldsymbol\omega\)가 이루는 평면 안. 막대와 \(\boldsymbol\omega\)의 각 \(\alpha\): \[ \boldsymbol\omega=(0,\ \omega\sin\alpha,\ \omega\cos\alpha). \]
  2. 주관성 모멘트(질점이 \(x_3\)축 위): \(I_1=I_2=(m_1+m_2)b^2\), \(I_3=0\).
  3. \(\vb L=(0,\ (m_1+m_2)b^2\omega\sin\alpha,\ 0)\) — 막대에 수직이고 \(\boldsymbol\omega\)와 각 \(90°-\alpha\).
  4. 물체가 돌면 \(\vb L\)은 \(\boldsymbol\omega\) 둘레로 원뿔을 그린다 → \(\dot{\vb L}\ne0\) → 외부 토크가 필요. Euler 방정식(U22, \(\dot{\boldsymbol\omega}=0\)): \[ N_1=-(I_2-I_3)\omega_2\omega_3=-(m_1+m_2)b^2\omega^2\sin\alpha\cos\alpha,\quad N_2=N_3=0 . \] 토크는 \(x_1\)(막대와 \(\boldsymbol\omega\) 평면에 수직) 방향, 크기는 \(\alpha=45°\)에서 최대. 베어링이 계속 이 짝힘을 공급 — 균형 안 맞는 바퀴가 흔들리는 이유(동적 불균형).
유도 3평면 진자를 텐서로 — Example 11.4
  1. 길이 \(b\)인 막대 끝에 \(m_1\), 중간(\(b/2\))에 \(m_2\). 원점 = 매단 점, \(\uv e_1\) 막대 방향, \(\uv e_3\) 회전면에 수직. \(\boldsymbol\omega=\dot\theta\uv e_3\).
  2. 모든 질량이 \(x_1\)축 위 → \(I_{33}=m_1b^2+m_2b^2/4\), 비대각 0. \(L_3=I_{33}\dot\theta\).
  3. 중력 토크: \(\vb r\times m\vb g\)의 \(3\)성분 \(=-(m_1b+m_2b/2)g\sin\theta\). \(\dot L_3=N_3\): \[ \omega_0^2=\frac{g}{b}\,\frac{m_1+m_2/2}{m_1+m_2/4}. \] 검산: \(m_2\to0\): \(g/b\) ✓, \(m_1\to0\): \(2g/b\) (길이 \(b/2\)) ✓.
