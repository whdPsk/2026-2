A partially linearly polarized beam is measured through a rotating linear polarizer: \(I_{\max}=1.03\), \(I_{\min}=0.97\) (arbitrary units). Find Π, \(I_{\rm pol}\), \(I_{\rm unpol}\). What \(I_{\max}/I_{\min}\) corresponds to typical starlight (Π ≈ 1.5%)?
(번역) 회전 편광판으로 측정한 최대·최소 세기에서 편광도를 구하라. [[L05.s12]]
풀이\(\Pi=(I_{\max}-I_{\min})/(I_{\max}+I_{\min})\)
  1. \(I_{\max}=\frac12I_{\rm unpol}+I_{\rm pol}\), \(I_{\min}=\frac12I_{\rm unpol}\) (무편광은 반만 통과). [[S0915.30]]
  2. \(I_{\rm pol}=I_{\max}-I_{\min}=0.06\), \(I_{\rm unpol}=2I_{\min}=1.94\), \(I=2.00\).
  3. \(\Pi=0.06/2.00=3\%\).
  4. 역으로 \(I_{\max}/I_{\min}=(1+\Pi)/(1-\Pi)\): Π = 1.5% → 1.030, Π = 10% → 1.22. [[L05.s14]]
결과

Π = 3%, I_pol = 0.06, I_unpol = 1.94. 별빛(1.5%)은 필터를 돌려도 세기 변화가 ~3%뿐 → 관측이 어렵고 비싸지만 정보가 좋다.

스케일편광도는 대개 몇 %, 강하면 ~10%, 드물게 30–40%. [[S0915.29, S0915.30]]
+α Stokes로 I = 2, Q = 0.03, U = 0.052, V = 0이면 Π와 편광각은?
스스로 채점:
Answer

√(Q²+U²) = 0.060 → Π = 3.0%; χ = ½ atan2(0.052, 0.03) ≈ 30°.

+α 완전 선편광(Π = 100%)이면 I_min은?
스스로 채점:
Answer

0 — 수직 방향 필터는 아무것도 통과시키지 않는다(Malus: cos²90° = 0).
