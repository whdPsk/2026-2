Example: For Hα 6563 Å lines, A₂₁ = 4.4×10⁷ s⁻¹ — Δν_L, Δλ_L? cf. Doppler Δλ_FWHM in a cloud with T=10⁴ K. (번역) Hα의 자연 선폭을 구하고 10⁴ K 도플러 폭과 비교하라. [[L04.s10c]]
풀이[[S0910.23]]
  1. γ≈A₂₁(이것 하나만 사용) → \(\Delta\nu_L=\gamma/2\pi=4.4\times10^7/2\pi=7.0\times10^6\) Hz. [[L04.s10b]]
  2. \(\Delta\lambda_L=(\lambda_0/\nu_0)\Delta\nu_L=\lambda^2\Delta\nu/c=1.0\times10^{-4}\) Å.
  3. 도플러: \(\Delta\lambda_D=(\lambda/c)\sqrt{2kT/m_H}=0.28\) Å, FWHM=1.665×0.28=0.47 Å. [[L04.s8c]]
결과

자연 폭 10⁻⁴ Å — 분광 분해능(0.1–0.01 Å)으로 구별 불가, 도플러(PPT 0.35 Å)에 3000–5000배 묻힘.

수치 의심PPT 0.35 Å / 녹음 "3.3" / 순수 수소 열운동 재계산 0.47 Å — 슬라이드 값의 가정 확인 필요. 결론(자연 폭 관측 불가)은 동일.
+α 도플러 FWHM이 자연 폭(10⁻⁴ Å)과 같아지려면 T는?
스스로 채점:
Answer

FWHM∝√T → T=10⁴×(10⁻⁴/0.47)²≈5×10⁻⁴ K — 비현실적.

+α 그래도 로렌츠 꼴을 배우는 이유는?
스스로 채점:
Answer

충돌 넓어짐이 같은 로렌츠 꼴(Γ=γ+2ν_col)이고 고밀도에서 ν_col≫γ가 되어 날개를 지배하기 때문.
